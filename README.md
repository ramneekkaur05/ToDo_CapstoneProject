# Todo Application (React + Express + SQLite)

## Prerequisites
- Node.js 18+

## Setup

### 1) Install dependencies
```
cd "X:\\MAIN AR\\server" && npm install
cd "X:\\MAIN AR\\client" && npm install
```

### 2) Run the servers (in two terminals)
```
cd "X:\\MAIN AR\\server" && npm run dev
```
```
cd "X:\\MAIN AR\\client" && npm run dev
```

Open the client at `http://localhost:5173`. The client proxies API requests to `http://localhost:4000`.

## Features
- Add todos
- List todos
- Toggle completed
- Rename todos (double-click title)
- Delete todos
